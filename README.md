# Python for Security Automation

These are hands-on labs from the Google Cybersecurity Certificate (Automate Cybersecurity Tasks with Python course). Each lab uses course-provided sample data and was completed in Jupyter Notebook with Python 3.

## Labs

| Lab | What it covers | Key skills |
| --- | --- | --- |
| [Conditional Statements](01-conditional-statements/) | Operating system update checks, and whether a user is approved and logging in during organization hours | `if`/`elif`/`else`, comparison and logical operators, allow-list checks with `in` |
| [Iterative Statements](02-iterative-statements/) | Connection error messages, IP allow list checks, and employee ID generation | `for` and `while` loops, `range()`, `break`, iterating through IP lists |
| [Functions](03-functions/) | Displaying a security alert and turning a list of approved usernames into a readable string | Defining and calling functions, loops, string concatenation |
| [Parameters and Return](04-parameters-and-return/) | Login analysis with built-in functions, a custom `analyze_logins()` function, and a login-ratio alert | `sorted()`/`max()`, parameters, `return` values, conditionals |
| [Strings](05-strings/) | Standardizing a short employee ID, extracting characters from a device ID, and parsing a URL | `str()`, `len()`, concatenation, indexing, slicing, `.index()` |
| [Lists](06-lists/) | Maintaining approved usernames and assigned devices, then building a login algorithm that checks both | `append()`/`remove()`, parallel lists, indexing, conditionals |
| [Regular Expressions](07-regular-expressions/) | Extracting device IDs that need an OS update, then extracting and flagging IP addresses in a login log | Regular expressions with the `re` module, `re.findall()`, log and IP analysis |

## Skills Demonstrated

- Conditional statements (`if`, `elif`, `else`)
- Loops (`for`, `while`, `range()`, `break`)
- Functions
- Parameters and return values
- Strings
- Lists
- Regular expressions with the `re` module
- Log and IP analysis

## Tools Used

- Python 3
- Jupyter Notebook (course lab environment)
